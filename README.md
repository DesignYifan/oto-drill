# 音声ドリル

フォルダの中の音声を番号順に並べて、**速度・繰り返し回数・曲間の間**を決めて聴くためのプレイヤー。
語学教材の連番 mp3 を1本ずつ開く手間をなくすために作った。

**→ https://designyifan.github.io/oto-drill/**

開いて「フォルダを選ぶ」を押すか、Finder からフォルダをそのまま画面に落とす。

## できること

- フォルダの中の音声（mp3 / m4a / wav / aac / ogg / flac など）を番号順に並べる
- **再生・前後・5秒送り・速度は画面のいちばん下に出したまま。**本文や一覧をどこまでたどっても、上に戻らずに止められる
- **音声の一覧はたためる。**たたむと本文が画面いっぱいに広がる。開け閉めは覚えている
  - 広いとき：ヘッダーの「一覧を隠す」で、右の列ごと消える
  - 狭いとき（窓を半分にして教科書と並べるとき）：一覧の頭の「一覧を隠す」で**下にたたむ。**開ける帯は画面の下に残る
- **前に開いたフォルダを次も開く**（下の「次も同じフォルダから始める」）
- 1本終わると自動で次へ
- 速度 0.5×〜2.0×。**音程は変わらない**（`preservesPitch`）。矢印キーで 0.1 刻みの微調整も可
- 5秒戻す／進む
- 1本を 2・3・5回、または「ずっと」繰り返してから次へ
- 次に行くまで 0〜5秒あける（復唱用）
- 最後に聴いた位置・聴き終わった本・設定を覚えている
- 番号や名前で一覧をしぼる

### キーボード

| キー | |
|---|---|
| `space` | 再生／停止 |
| `←` `→` | 5秒 |
| `⇧←` `⇧→` | 前後の本 |
| `↑` `↓` | 速度 |
| `0` | 速度を 1.0 に |
| `R` | 頭から |

## 音声はどこにも送られない

ブラウザの中だけでファイルを参照している（`URL.createObjectURL`）。
サーバーに上がるのはこの HTML だけで、選んだ音声はこの端末から出ない。

覚えている内容は `localStorage`（キーは `otodrill:`）に入る。ブラウザを変えると引き継がれない。

## 次も同じフォルダから始める

一度開いたフォルダは覚えていて、次に開いたときそのまま出る。最後に聴いていた位置から続く。

覚えているのは**フォルダへの手掛かりだけ**で、音声そのものは持たない（`IndexedDB` の `otodrill`）。
ブラウザが許可を忘れていたときは、ヘッダーに「前の ◯◯ を出す」が出るので1回押す。

⚠️ **これが効くのは Chrome と Edge。**（`showDirectoryPicker` のある環境）
Safari・Firefox と、HTML をダブルクリックで開いた場合は、これまで通り毎回選ぶ。

## 読む（音声と同じフォルダに置いたファイルを一緒に読む）

フォルダの中に下のファイルがあれば、自動で拾って本文を出す。無ければ今まで通り再生だけ。

| ファイル | 何が起きるか |
|---|---|
| `transcript.json` | 本文が出る。**再生に合わせて今の文が光る**／文をクリックでそこへ飛ぶ／**単語をクリックで意味** |
| `lexicon.json` | 単語を引いたとき、漢越語（漢字・音読み）と手元の語釈を先に出す |
| `notes.json` | 文法メモを、その文の下に出す。⛔ 1文ずつ書くのではなく**型**を書いて当てる（同じ型の練習が何十回も出るため）。`not` を書くと、その語を含む文では出さない |

⛔ **これらは公開していない。** このリポジトリに入っているのは `index.html` だけで、
教材の本文は各自の端末のフォルダの中にしか無い。市販教材の中身を再配布しないため。

単語を引くと Wiktionary も一緒に引く（無料・鍵なし）。引けなくても他の表示は残る。

### 貯める

引いた語は「**その語が出てきた文ごと**」貯まる。⛔ 語だけを取り出して並べない
（文脈から切り離した語は覚えても死ぬため）。ヘッダーの「貯めた語を書き出す」で TSV が落ちる。

### 作り方

文字起こしと lexicon は `~/Downloads/WIP/_course/26295/` のスクリプトで作る。

## 練習（`practice.json` があるときだけ出る）

聴くだけだと、自分で選んで確かめられないので覚えられない（2026-09-30）。ヘッダーの「聴く｜練習」で切り替える。

| 面 | |
|---|---|
| 表 | 本の表をそのまま並べる。どのマスも押せばその1音だけ鳴る |
| 聞いて選ぶ | 1音鳴る → 4つから選ぶ。似た音から先に選択肢に出す。答えたあとは選択肢を押して聞き比べられる |
| 見て言う | 字を見て自分で言う → 答えを聞く → 言えた／言えなかった |
| 並べる | 文を聞いて、ばらばらの語を聞こえた順に押す（文の組だけ） |
| 穴埋め | 文から1語抜く。không・đã・là のような文法の語を優先して抜く。答えると文が鳴る |
| 聞いて書く | 音だけ聞いて書く。語ごとに「合っている／声調・記号だけ違う／違う／抜け」を返す。書いて正解すると箱が2つ上がる |

聞いて書くは、Mac のベトナム語入力でも、画面の Telex（aa→â　dd→đ　s f r x j で声調）でも打てる。

## 見渡す

ヘッダーの「見渡す」で、どこまで覚えたかを見る。

- 覚えた項目（箱3以上）・出会った語・今日答えた数・続けた日数
- 編とユニットごとの帯（未着手／覚えかけ／覚えた）。押すとその組の練習へ
- 練習ごとの正答率（直近50回）と、12週の積み上げ
- 語の地図：よく出る語から並べ、その語を含む文の進み具合で色を付ける。書いて正解した語には下線
- よく間違えるもの

答えの履歴は `localStorage` の `otodrill:hist`（`[時刻, 項目, 練習, 正誤]`）、書いて正解した語は `otodrill:typed`。

- 練習する組はヘッダーの下で選ぶ。1組・編ごと全部・すべて、から選べる
- 音声は切らない。元の mp3 の `start`〜`end` だけ鳴らす（項目ごとに `src` を持てる。文法編は1ユニットが4〜6本にまたがる）
- 綴りが音声の聞き取りのもの（`checked:false`）は、表に「本とはまだ照らしていません」と出る
- 覚えたかは5段の箱で持つ（`localStorage` の `otodrill:srs`）。間違えると1段目に戻って先に出る
- 記録は項目の `id`（`vi.letter.a` のように、本ではなく言語の側の名前）で持つ。別の本に同じ音が出ても記録がつながる
- `practice.json` も公開していない。作り方は `~/Downloads/WIP/_course/26295/build_practice.py`

## 教材（2026-10-01）

教材ごとに、進み具合・紙の問題・文法・語彙を1か所で見る。ヘッダーの「教材」で開く。**練習用のファイルが無いフォルダでも出る。**

| 面 | |
|---|---|
| 教材の一覧 | 開いたことのある教材。押すとそのフォルダを開き直す（Chrome・Edge。許可を1回聞かれる） |
| 進み具合 | 課ごとに、聴いた本数／練習の正答率（直近50回）／紙の問題の点／覚えた語 |
| 紙の問題 | 本の練習問題を1問ずつ ○ → △ → × で付ける。問題は解きながら足す。**前の印は消さずに履歴に残る**。点は ○＝1・△＝0.5 |
| 文法 | `notes.json` の型を課ごとに。押すと、その型を含む本文の文が並び、押せば鳴る |
| 語彙 | `lexicon.json` の語と貯めた語を課ごとに。左の帯の色が覚えた具合。押すとその語を含む文が鳴る。台帳が無い教材は、本文に出た音節を並べる |
| 記録を運ぶ | `otodrill:` の記録を丸ごと JSON に書き出す／読み込む（別のブラウザや端末へ運ぶため） |

課は、フォルダの中の `book.json` で決める。無ければサブフォルダごと（無ければ全体で1つ）。

```json
{ "version": 1, "id": "tvcs1", "title": "Tiếng Việt cơ sở 1", "answers": "答えのありか",
  "lessons": [ { "id": "b01", "title": "Bài 1", "match": "^B01 " } ] }
```

- 課に音声を当てるのは `match`（ファイル名の正規表現）・`tracks`（ファイル名の一覧）・`decks`（`practice.json` の組）のどれか
- 語と文法の型は、`lesson` が書いてあればその課、無ければ**最初に3語以上の文で出てくる課**に置く。`"assign": false` の課（発音の練習など）は、ほかに無いときだけ使う
- 紙の問題の記録は `otodrill:paper:<教材id>`、自分で足した問題は `otodrill:paperdef:<教材id>`
- `book.json` も公開していない

## 課を進める（2026-10-01）

教材の中の「課を進める」で、1つの課を **①聴く ②単語 ③練習 ④紙の問題** の順にくぐる。各段に「済んだ」の条件があり、全部済むと「次の課へ」が光る。

| 段 | 済んだ |
|---|---|
| 聴く | その課の本文・繰り返しの音声を全部聴き終えた |
| 単語 | その課の語に全部「覚えた」が付いた（練習で箱3以上になった語にも自動で付く） |
| 練習 | その課の項目に一度ずつ正解した（「この課の練習を始める」で、その課だけに絞って始まる） |
| 紙の問題 | 全部の問に ○△× が付いた |

- 紙の問題は、`book.json` の `exercises[].tracks` に書いた**その問題の音声**と並べて出す。「この問題の音声」で聴く画面に移り、聴く画面の上でも印を付けられる
- 問題の音声は、本文に答えが入っているので、聴く画面では本文を隠す（「本文を出す」で出る）
- 問の数が分からない問題は、画面で入れる（`otodrill:excount:<教材id>`）。「覚えた」は `otodrill:wknown:<教材id>`

## 解説（答えたあと）（2026-10-01）

練習で答えると、正誤のすぐ下に解説が出る。

| | 出どころ |
|---|---|
| 語ごとの意味（語のすぐ下に書き添える） | `gloss.json`（機械の訳）。無ければ `lexicon.json` の語を、長い語から先にまとめて引く |
| 文の意味 | `gloss.json` |
| 違い（選んだ語と正しい語の意味） | 同上 |
| 文法 | `notes.json`（手で書いた型）。当てはまる型が無いときだけ `gloss.json` の要点 |
| 要確認 | 別のモデルの判定で引っかかった訳に、理由つきで出す |

- `gloss.json` は `~/Downloads/WIP/_course/26295/build_gloss.py` で作り、`check_gloss.py` で判定する。⛔ 公開していない
- 見渡すの「語の地図」は、押すと音と一緒に意味が画面の下に出る

## Mac で開く・これどういうこと？・質問帳（2026-10-02）

**`tools/oto-drill.command` をダブルクリック**すると、ページ（`http://localhost:8790/`）と手元の AI（`mlx_lm.server`・Qwen3.8-27B・`8791`）が立ち、Chrome で開く。ウィンドウを閉じると両方止まる。

- 公開ページ（https）からは手元の AI を呼べない（ブラウザが止める）。手元から開けば呼べる
- 解説と引いた語の窓の下に「これどういうこと？」。AI は**文・訳・語・文法メモを材料に**答える（材料なしだと崩れる）
- 聞いたことは全部**質問帳**に1行（`質問帳/<言語>/<端末>.jsonl`）。Claude が確かめた答えは `質問帳/<言語>/claude.jsonl`。画面では「確かめた答え」＞「AI の答え（未確認）」＞「答え待ち」の順に出す
- Claude は `python3 tools/qa.py 未回答 <フォルダ>` で読み、`qa.py 答える` で足す

## 記録の連動（2026-10-02）

設定の「記録の連動」で iCloud のフォルダ（vault の `008_project/LanguageCourse/音声ドリル/`）を選ぶと、記録を `記録/<端末>.jsonl` に足していき、開くときに全部の端末の分を読んで合わせる。端末ごとに別のファイルなので同期でぶつからない。箱は答えた出来事から数え直す。設定は端末ごと。
