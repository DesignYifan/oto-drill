# 音声ドリル

フォルダの中の音声を番号順に並べて、**速度・繰り返し回数・曲間の間**を決めて聴くためのプレイヤー。
語学教材の連番 mp3 を1本ずつ開く手間をなくすために作った。

**→ https://designyifan.github.io/oto-drill/**

開いて「フォルダを選ぶ」を押すか、Finder からフォルダをそのまま画面に落とす。

## できること

- フォルダの中の音声（mp3 / m4a / wav / aac / ogg / flac など）を番号順に並べる
- 1本終わると自動で次へ
- 速度 0.5×〜2.0×。**音程は変わらない**（`preservesPitch`）。矢印キーで 0.1 刻みの微調整も可
- 5秒戻す／進む
- 1本を 2・3・5回、または「ずっと」繰り返してから次へ
- 次に行くまで 0〜5秒あける（復唱用）
- 最後に聴いた位置・聴き終わった本・設定を覚えている
- 番号や名前で一覧をしぼる

### キーボード

| キー | |
|---|---|
| `space` | 再生／停止 |
| `←` `→` | 5秒 |
| `⇧←` `⇧→` | 前後の本 |
| `↑` `↓` | 速度 |
| `0` | 速度を 1.0 に |
| `R` | 頭から |

## 音声はどこにも送られない

ブラウザの中だけでファイルを参照している（`URL.createObjectURL`）。
サーバーに上がるのはこの HTML だけで、選んだ音声はこの端末から出ない。

覚えている内容は `localStorage`（キーは `otodrill:`）に入る。ブラウザを変えると引き継がれない。

## 読む（音声と同じフォルダに置いたファイルを一緒に読む）

フォルダの中に下のファイルがあれば、自動で拾って本文を出す。無ければ今まで通り再生だけ。

| ファイル | 何が起きるか |
|---|---|
| `transcript.json` | 本文が出る。**再生に合わせて今の文が光る**／文をクリックでそこへ飛ぶ／**単語をクリックで意味** |
| `lexicon.json` | 単語を引いたとき、漢越語（漢字・音読み）と手元の語釈を先に出す |
| `notes.json` | 文ごとの文法メモを、その文の下に出す |

⛔ **これらは公開していない。** このリポジトリに入っているのは `index.html` だけで、
教材の本文は各自の端末のフォルダの中にしか無い。市販教材の中身を再配布しないため。

単語を引くと Wiktionary も一緒に引く（無料・鍵なし）。引けなくても他の表示は残る。

### 貯める

引いた語は「**その語が出てきた文ごと**」貯まる。⛔ 語だけを取り出して並べない
（文脈から切り離した語は覚えても死ぬため）。ヘッダーの「貯めた語を書き出す」で TSV が落ちる。
