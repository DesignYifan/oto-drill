# 音声ドリル

フォルダの中の音声を番号順に並べて、**速度・繰り返し回数・曲間の間**を決めて聴くためのプレイヤー。
語学教材の連番 mp3 を1本ずつ開く手間をなくすために作った。

**→ https://designyifan.github.io/oto-drill/**

開いて「フォルダを選ぶ」を押すか、Finder からフォルダをそのまま画面に落とす。

## できること

- フォルダの中の音声（mp3 / m4a / wav / aac / ogg / flac など）を番号順に並べる
- 1本終わると自動で次へ
- 速度 0.5×〜2.0×。**音程は変わらない**（`preservesPitch`）。矢印キーで 0.1 刻みの微調整も可
- 5秒戻す／進む
- 1本を 2・3・5回、または「ずっと」繰り返してから次へ
- 次に行くまで 0〜5秒あける（復唱用）
- 最後に聴いた位置・聴き終わった本・設定を覚えている
- 番号や名前で一覧をしぼる

### キーボード

| キー | |
|---|---|
| `space` | 再生／停止 |
| `←` `→` | 5秒 |
| `⇧←` `⇧→` | 前後の本 |
| `↑` `↓` | 速度 |
| `0` | 速度を 1.0 に |
| `R` | 頭から |

## 音声はどこにも送られない

ブラウザの中だけでファイルを参照している（`URL.createObjectURL`）。
サーバーに上がるのはこの HTML だけで、選んだ音声はこの端末から出ない。

覚えている内容は `localStorage`（キーは `otodrill:`）に入る。ブラウザを変えると引き継がれない。

## 中身

`index.html` 1枚。ビルドも依存もない。ダウンロードしてダブルクリックでも動く。
